# 02 模擬畫面設計 (lotto_app)

## 🎨 1. 介面視覺風格與設計規範

`lotto_app` 採用高品質深色質感主題配色彩球系統，強調專業數據分析與極致的觸控體驗。

* **主題色系**：
  * **背景底色**：深灰/黑灰色 (`#1A1A1A` ~ `#262626`)，突顯彩色獎號與文字。
  * **強調主色**：香檳金 / 金黃色 (`#FFD700` / `#FFC107`)，象徵好運與財富。
  * **輔助藍色**：科技藍 (`#2196F3`)，用於主要執行按鈕與動作觸發。
* **彩球視覺設計 (Ball Icons)**：
  * **紅球/主球**：紅黃漸層圓形標籤，白字粗體。
  * **藍球/特別號**：深藍/天藍圓形標籤，區分第一區與第二區/特別號。
  * **高亮球 (Highlight)**：自選中獎號碼以鮮豔螢光綠或黃色高亮圈邊顯示。
* **字型規範**：統一採用 `NotoSansTC-Regular.ttf` 中文字體，確保跨平台渲染一致。

## 💬 3. 彈窗與互動組件設計 (Popups & Dialogs)

### 3.1 提取自選號彈窗 (Load Custom Numbers Popup)
- **結構**：ScrollView 列表中展示使用者先前儲存的組合。
- **互動設計**：
  - **單擊 (Tap)**：選取該組號碼，自動填入當前選號盤並關閉彈窗。
  - **長按 (Long Press)**：觸發安全防護，彈出「確認刪除此自選號組合？」二次確認對話框，防止意外誤刪。

### 3.2 隱私權政策與免責聲明彈窗 (Privacy Policy Popup)
- **視覺**：全螢幕 95% 寬度之黑灰底色彈窗，頂部金黃色標題，搭配高對比白色文字。
- **內容引擎**：動態讀取並解析 Markdown 文件，自動將 Markdown 標題高亮（天藍色/淡黃色），並支援超連結點擊跳轉。

### 3.3 版本更新提示彈窗 (App Version Update Popup)
- **觸發**：App 啟動時自動與 Supabase 比對版本號。
- **按鈕**：提供「立即更新」（跳轉商店頁面）與「稍後再說」（強迫更新模式下隱藏）。
