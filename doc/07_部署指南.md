# 07 部署與打包指南 (lotto_app)

本文件提供 `lotto_app` 在 **Windows 桌面端** 與 **Android 跨平台打包** 的完整環境建置、編譯打包步驟與實機排錯經驗手冊。

---

## 💻 1. 開發環境建置 (Development Environment)

### 1.1 Python 基礎環境
* **建議版本**：Python 3.11.x (64-bit)。
* **依賴套件安裝**：
```bash
pip install kivy==2.3.1 requests urllib3 certifi idna chardet
```

### 1.2 驗證本地執行
在專案根目錄下執行以下指令，確認 UI 與資料庫正常運作：
```bash
python main.py
```

---

## 🪟 2. Windows 桌面版打包 (PyInstaller)

可使用 PyInstaller 將專案打包為獨立的 `.exe` 執行檔。

### 2.1 打包指令與腳本
在專案根目錄下執行：
```bash
pyinstaller --noconfirm --onedir --windowed \
  --add-data "kv;kv" \
  --add-data "data;data" \
  --add-data "fonts;fonts" \
  --add-data "images;images" \
  --add-data "隱私權政策及免責聲明;隱私權政策及免責聲明" \
  --icon "images/goodluckicon512.png" \
  main.py
```

## 📱 3. Android APK 打包 (Buildozer / WSL2)

Android 打包推薦於 WSL2 (Ubuntu 22.04 LTS) 或 Linux 環境下使用 Buildozer 進行。

### 3.1 核心配置文件 `buildozer.spec` 重要參數
```ini
[app]
title = 好運自己選
package.name = goodluck
package.domain = com.lottotaiwan
source.dir = .
# 必須包含 md 與 html，確保隱私權政策檔案包含於 APK 內
source.include_exts = py,png,jpg,kv,ttf,json,db,md,html

# 依賴套件
requirements = python3,kivy==2.3.1,sqlite3,openssl,requests,urllib3,certifi,idna,chardet

# 權限設定 (連線 Supabase 需網際網路權限)
android.permissions = INTERNET

orientation = portrait
fullscreen = 1
android.minapi = 21
```

### 3.2 打包執行指令
```bash
# 清除舊編譯快取
buildozer android clean

# 打包 Debug APK
buildozer -v android debug
```

## 🔧 4. Android 實機常見問題排錯手冊 (Troubleshooting)

基於 `doc/android_troubleshooting_guide.md` 彙整之實戰經驗：

### 4.1 Android 畫面縮小成左下角小視窗
* **現象**：APP 於高 DPI Android 手機上啟動時，介面縮小集聚在螢幕左下角。
* **原因**：Kivy window 尺寸與 Android 原生 Surface 視窗初始化競爭。
* **解法**：在 `main.py` 頂部置入 Window 尺寸適應監聽器，強制觸發一次 `Window.trigger_keyboard_height()` 或視窗 resize 事件。

### 4.2 SQLite 資料庫檔案遺漏與權限錯誤
* **現象**：Android 實機上點選查詢無反應或閃退。
* **解法**：確認 `buildozer.spec` 的 `source.include_exts` 包含 `db`，且程式碼中資料庫路徑採用 `os.path.abspath(os.path.join(os.path.dirname(__file__), ...))` 動態取得絕對路徑。

### 4.3 雙重觸控重複觸發 (Double Touch) 導致選中狀態抵消
* **現象**：手速較快或多點觸控時，選號按鈕點擊無效。
* **解法**：核心按鈕組件中已引入 **100ms 觸控冷卻計時器 (Debounce)**，於短時間內鎖定重複觸發。
