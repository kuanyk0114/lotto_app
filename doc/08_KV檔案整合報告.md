# 08 KV 檔案整合報告 (lotto_app)

## 🎨 1. Kivy Language (KV) 整合架構總覽

`lotto_app` 採用 Kivy 獨有的 UI 宣告式語言（KV Language），實現 UI 佈局與 Python 業務邏輯的完全解耦。所有介面風格、佈局視窗、動畫與組件樣式均儲存於 `kv/` 資料夾中。

```
kv/
├── common.kv          # 全局公共樣式、主功能選單、彈窗與自訂按鈕定義
├── powerlotto.kv      # 威力彩雙區選號與結果佈局
├── biglotto.kv        # 大樂透選號與結果佈局
├── lotto539.kv       # 今彩539選號與結果佈局
├── lotto3star.kv      # 三星彩選號佈局
└── lotto4star.kv      # 四星彩選號佈局
```

## 📄 2. 各 KV 檔案結構與元件分析

### 2.1 `kv/common.kv` (核心靈魂檔案)
定義全局共用基礎組件與全域通用屬性：
1. **`LotteryImageButton`**：自訂圖像按鈕組件，支援正常狀態 (`source`) 與按下狀態 (`pressed_source`) 動態切換，並具備觸控音效與動畫回饋。
2. **`ResultBall`**：彩球渲染組件，根據球號與彩種屬性動態劃繪圓形 Canvas 背景與高亮邊框。
3. **`AdBannerArea`**：廣告與引流預留版位。
4. **`ExitConfirmPopup`**：離開 App 之二次確認對話視窗。
5. **`LotteryTypeScreen`**：主功能視窗 UI 結構，以 `GridLayout` 佈局各大彩種按鈕與近期獎號入口。

### 2.2 `kv/powerlotto.kv` ~ `kv/lotto4star.kv` (彩種專屬視窗)
各彩種選號頁面均遵循一致的頂中下三段式結構：
* **頂部列 (Top Bar)**：返回主頁按鈕、彩種標題 Logo。
* **中部選號區 (Number Grid Area)**：
  - `powerlotto.kv`：包含第一區 `GridLayout(cols=10)` 與第二區 `GridLayout(cols=8)`。
  - `lotto3star.kv` / `lotto4star.kv`：包含按位數分類的垂直矩陣。
* **功能按鈕列 (Action Bar)**：高 50dp 的水平 `BoxLayout`，存放「查詢選號」、「查重複獎號」、「中獎詳情」、「儲存」、「提取」五大動作按鈕。
* **底部結果區 (Result List ScrollView)**：綁定 `BasePaginationMixin` 屬性，包含動態載入指示器與彩球清單。

## 🔗 3. UI 與 Python 代碼綁定機制 (Bindings)

### 3.1 屬性雙向綁定 (Property Bindings)
KV 檔案中廣泛使用 `root` 與 `id` 選擇器進行雙向數據綁定：
```kv
ScrollView:
    on_scroll_stop: root.on_scroll_stop(self)
    BoxLayout:
        id: result_container
        height: self.minimum_height
```

### 3.2 事件處理器 (Event Handlers)
動作按鈕直接綁定 Python 視窗類別的方法：
```kv
Button:
    text: '查詢選號'
    on_release: root.query_numbers()
Button:
    text: '儲存'
    on_release: root.save_custom_numbers()
```

## 💡 4. 重構與維護建議

1. **模組化抽離**：目前各大彩種 KV 檔案中的動作按鈕列程式碼高度相似，建議未來可進一步抽離為 `ActionButtonBar` 公共 KV 組件，提升維護效率。
2. **高 DPI 適應**：所有硬編碼之尺寸單位均已全面使用 `dp()` 與 `sp()`，維持跨裝置體驗一致。
